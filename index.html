      Comment trouver l'ID d'une chaîne ?

      Sur YouTube, ouvrez la chaîne → « plus » dans la description → « Partager la chaîne » → « Copier l'ID de la chaîne » (il commence par UC). Vous pouvez aussi coller un lien youtube.com/channel/UC… ou un lien de playlist (…?list=PL…). Les @pseudos nécessitent une clé d'API YouTube (ci-dessous).

      Comment obtenir une clé d'API YouTube (gratuit) ?
      1. Allez sur console.cloud.google.com et créez un projet.
      2. « API et services » → « Bibliothèque » → activez YouTube Data API v3.
      3. « Identifiants » → « Créer des identifiants » → « Clé API ».
      4. Conseillé : restreignez la clé à cette API et à l'adresse de votre site (« Sites web »).

      La clé reste dans ce navigateur. Elle sert aux photos et aux vidéos des chaînes, et aux @pseudos.
